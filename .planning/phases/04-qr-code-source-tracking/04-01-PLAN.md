<objective>
Implement in-process print-ready QR code generation (PNG/SVG), source management API, downloadable QR assets, and dashboard sources UI for Reception QR and Instagram link channels at ₹0 infrastructure cost.
</objective>

<tasks>
1. **QR Code Engine**: Build in-process QR code generator (`server/src/services/qr.service.ts`) using `qrcode` library to generate PNG Data URLs, vector SVG markup, and high-resolution binary buffers.
2. **Sources REST API**: Build `GET /api/v1/sources`, `GET /api/v1/sources/reception/qr.png`, and `GET /api/v1/sources/reception/qr.svg` (`server/src/routes/sources.ts`, mounted in `server/src/index.ts`).
3. **QR Service Unit Tests**: Test QR generation, error correction levels, SVG markup validity, PNG buffer sizes, and source URL construction (`server/src/services/__tests__/qr.test.ts`).
4. **Sources Management Page**: Create modern, minimal Linear-inspired `SourcesPage.tsx` with live QR preview, print downloads (PNG/SVG), and one-click copy for the Instagram link.
5. **Dashboard Navigation Integration**: Add navigation header tabs linking between Overview and QR / Link sources (`client/src/pages/DashboardPage.tsx`, `client/src/App.tsx`).
6. **Verification**: Run `vitest`, `tsc --noEmit`, and `vite build`.
</tasks>
