<objective>
Implement complete database schema operations, authentication service, session management, auth REST API endpoints, tenant isolation middleware, frontend auth context with login/signup/dashboard views, and unit tests for Phase 2.
</objective>

<tasks>
1. **Validation & Session Service**: Zod input validation schemas and crypto-based session management (`validation.ts`, `session.ts`).
2. **Auth Service**: Scrypt password hashing with unique salt and constant-time verification, plus atomic user+business+settings registration (`auth.service.ts`).
3. **Tenant & Auth Middleware**: Session extraction, validation, and strict `business_id` injection from session (`middleware/auth.ts`).
4. **Auth Endpoints**: Register, login, logout, and me endpoints with cookie handling and error states (`routes/auth.ts`, mounted in `server/src/index.ts`).
5. **Frontend Auth System**: React auth context, protected route wrapper, and Linear/Stripe-styled Login and Signup pages (`auth.tsx`, `LoginPage.tsx`, `SignupPage.tsx`, `DashboardPage.tsx`).
6. **Tests & Seed Script**: Unit tests for crypto hashing/validation and development database seeding script (`auth.test.ts`, `seed.ts`).
</tasks>
